# Execution checklist

Required limits: total shares, total notional, per-order shares, per-order notional, symbol concentration, max loss, max orders, max retries, quote age, price deviation, cancel interval, and valid-until time.

Required branches: suspension, up/down limit, odd lot, reject, duplicate, partial fill, cancel failure, network loss, stale callback, restart, and reconciliation mismatch. Default action for missing/unknown input is reject and alert.
